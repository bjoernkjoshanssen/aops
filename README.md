# omlib

omg, it's omlib!

The Oahu Math Library project uses the proof assistant Lean to formalize solutions of math problems appearing in [Oahu Mathematics League](https://www.oahumath.org/) competitions and Art of Problem Solving books (Rusczyk's Introduction to Geometry, in particular). One of the interesting features is the appearance of oriented angles, which are often left implicit in exercises and exam questions.
